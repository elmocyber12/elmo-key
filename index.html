予測変換AI ELMO_key 予測よそく変換へんかんAI ELMO_key

打つそばから、漢字に。PC の中の AI が前後の文脈を見て、変換を整えます。スペースを押さなくても、入力中から漢字かな交じりに変わる日本語入力ソフトです。

Windows 版をダウンロード インストールの手順を見る

Windows 10 / 11（64 ビット）最新版約 110 MB

試験版v1.2.11

通常版の機能に加えて、次の機能を試せます。

  • Ctrl + E 英語にする会議の時間が3時に変わりました → The meeting time has been changed to 3 PM.
  • Ctrl + R 「だ・である」調にする次回の会議は来月十日に開催します。 → 次回の会議は来月十日に開催する。
  • Ctrl + Y やさしい日本語にする運動会は雨天の場合翌日に順延します → 運動会は 雨なら、次の日 にします。
  • Ctrl + Shift + F1〜F6 学年別漢字モード（小1〜小6）に切り替えF12 で解除。入力中の札に「ELMO_key 小2」のように出ます

AI の書き直しは、文字を打っている途中（Enter を押す前）にキーを押します。Enter で確定、Esc で元に戻ります。別に AI のモデル（約 2GB）が必要です。

インストールするだけで、どれも最初から使えます。

01

スペースなしで漢字に

入力しているそばから、自動で漢字かな交じりに変わります。そのまま Enter で確定できます。

02

AI が文脈を見て整える

前後の文章を見て、PC の中の小さな AI が変換を直します。AI が間に合わないときも入力は止まりません。

03

打った文字は外に出ない

変換も AI も、すべて PC の中で動きます。入力した内容をインターネットに送らず、オフラインでも使えます。

動作環境

ふつうの事務用 PC で動くように作っています。グラフィックボード（GPU）は要りません。

OSWindows 11 / Windows 10（バージョン 1809 以降）
種類64 ビット版（x64）。ARM 版の Windows には対応していません。
メモリ8 GB 以上をおすすめします
インストール管理者の許可が必要です（途中で「はい」を押す画面が出ます）
料金無料（オープンソースソフトウェア）
自分の PC が 64 ビット版か確かめるには

スタート → 設定 → システム → バージョン情報（Windows 10 では 詳細情報）を開き、「システムの種類」を見てください。

「64 ビット オペレーティング システム、x64 ベース プロセッサ」と書かれていれば使えます。

インストールの手順

5 分ほどで終わります。途中で出てくる確認の画面も、ひとつずつ説明します。

  1. 1

    ダウンロードして開く

    上の Windows 版をダウンロード を押すと、ELMO_key_x64.msi が「ダウンロード」フォルダーに保存されます。保存されたファイルをダブルクリックして開きます。

    Microsoft Edge で「一般的にダウンロードされていません」と出たときは、右の … から 保存（または 保持する）を選んでください。新しいソフトで、ダウンロードした人の数が少ないと出る表示です。

  2. 2

    青い画面で「詳細情報」→「実行」

    「Windows によって PC が保護されました」という青い画面が出ます。エルモキーに有料の「デジタル署名」を付けていないために出る表示です。詳細情報 を押し、下に出てくる 実行 を押してください。

    注意：このページ以外から入手したファイルでは、この操作をしないでください。心配なときはファイルが本物か確かめる方法があります。

  3. 3

    「はい」で許可する

    「このアプリがデバイスに変更を加えることを許可しますか？」と聞かれたら はい を押します。インストールが始まり、1〜2 分で終わります。

    「はい」が押せず、管理者のパスワードを求められたときは、社内の PC 管理の担当者に相談してください。

  4. 4

    PC を再起動して使い始める（おすすめ）

    インストールが終わったら、PC を再起動します。再起動すると、最初から ELMO_key が選ばれた状態になります。メモ帳などで、そのまま日本語を打ってみてください。

    すぐに再起動できないときは、あとででもかまいません。その場合は、メモ帳などを新しく開いて使ってください（インストール前から開いていたアプリでは、使えないことがあります）。

    画面右下の表示が「A」のときは、打っても英字のままです。変換 キーを押して「あ」にしてください。

    ELMO_key になっていないときは、Windows キーを押しながら Space を押し、出てきた一覧から ELMO_key を選びます。毎回 ELMO_key にしたいときは、画面右下の「あ」か「A」を右クリック → プロパティ → その他 タブ → Windows の既定 IME に設定 を押してください（以前の設定に戻す で元に戻せます）。

基本の使い方

ふだんの日本語入力と同じ感覚で使えます。よく選ぶ漢字は覚えて、次から上のほうに出します。

そのまま打つローマ字で打つと、入力中から自動で漢字に変わります。
Enter表示されている文字をそのまま確定します。
Space違う漢字にしたいとき、候補の一覧から選びます。
Esc変換をやめて、打った読み（ひらがな）に戻します。
無変換英数（「A」）にします。英字をそのまま打てます。
変換ひらがな（「あ」）に戻します。

よくある質問

困ったときは、まずここを見てください。

青い警告の画面が出ました。大丈夫ですか？

「デジタル署名」がないソフトを開いたときに Windows が出す表示で、ウイルスが見つかったという意味ではありません。署名には毎年費用がかかるため、エルモキーでは付けていません。

ただし、このページ以外から入手したファイルや、「ウイルスが検出されました」と出たファイルは実行しないでください。

入力した文字が、どこかに送られることはありますか？

ありません。変換も AI の補正も PC の中で行い、AI が覚えた内容も PC の中に保存します。インストール時に、外部と通信しないよう Windows ファイアウォールの設定も追加します。

動きが重い、AI の補正を止めたい

エルモキーの設定画面で、AI の補正やライブ変換をオフにできます。オフにしても、ふつうの日本語入力として使えます。

設定画面は、画面右下の「あ」や「A」の表示を右クリックし、メニューの プロパティ から開きます。

元の Microsoft IME に戻したい・アンインストールしたい

一時的に戻すなら、Windows + Space の一覧から Microsoft IME を選びます。完全にやめるときは、次の手順でアンインストールします（Mozkey や Mozc も同じ手順です）。

  1. スタート → 設定 → アプリ → インストールされているアプリ を開きます（Windows 10 では アプリと機能）。
  2. 一覧の ELMO_key の右にある … から アンインストール を押します（Windows 10 では項目を押してから アンインストール）。
今まで登録した単語（ユーザー辞書）を使いたい

Microsoft IME に登録した単語は、まとめて取り込めます。

  1. 画面右下の「あ」や「A」の表示を右クリックし、メニューの 辞書ツール を開きます。
  2. 左下の 管理 → Microsoft IME のユーザ辞書をインポート を押します。
  3. 確認の画面で OK を押します。登録した単語が一覧に入れば完了です。辞書ツールを閉じると、変換に使われるようになります。

取り込まれるのは、単語の追加 で自分で登録した単語です。Microsoft IME が自動で覚えた変換は取り込まれません。

Google 日本語入力・ATOK・ことえりの単語は、それぞれの辞書ツールでテキスト形式に書き出してから、管理 → 新規辞書にインポート で取り込みます。Mozkey や Mozc で登録した単語は、そのまま引き継がれます。

決まり文句をすばやく入力したい（定型文）

短い読みで、メールの決まり文句が候補に出ます（1.1.1 以降）。Space で候補を開いて選んでください。

  • 「おせ」→ お世話になっております。／「いつおせ」→ いつもお世話になっております。
  • 「よろ」→ よろしくお願いいたします。／「ひきよろ」→ 引き続きよろしくお願いいたします。
  • 「おつ」→ お疲れさまです。／「ごかく」→ ご確認のほどよろしくお願いいたします。
  • 「とりいそ」→ 取り急ぎご連絡まで。／「おりかえ」→ 確認してから折り返しご連絡いたします。

書画カメラ、電子黒板、GIGAスクール構想など、教育関係の言葉も最初から入っています。

学校向けの機能（学年別漢字・ふりがな）

設定画面の 入力補助 タブ →「学校向け」で選べます（1.1.1 以降）。

  • 学年別漢字モード：選んだ学年（小学 1〜6 年）までに習う漢字だけを使います。それ以外の漢字を含む言葉はひらがなで表示します（例：小学 2 年なら「勉強」→「べんきょう」）。文部科学省の学年別漢字配当表にもとづいています。
  • ふりがなを付ける：「漢字（かんじ）」の形で読みを付けて入力します。

どちらかを使っている間は、AI ライブ補正は働きません。

試験版（1.2.11）では、Ctrl + Shift + F1〜F6 で小学 1〜6 年、Ctrl + Shift + F12 で解除に、キーですぐ切り替えられます。入力中の札に「ELMO_key 小2」のように今の学年が出ます。ほかのアプリのショートカット（Word の Ctrl + Shift + F12 など）とぶつかるときは、設定画面の「一般」タブのキー設定で、別のキーに変えたり外したりできます。

AI で文章を書き直したい（英語・やさしい日本語など、試験版）

試験版（1.2.11）の機能です。文字を打っている途中（確定する前）に次のキーを押すと、AI が書き直します。Enter で確定、Esc で元の文に戻ります。

  • Ctrl + E：英語
  • Ctrl + R：「だ・である」調
  • Ctrl + Y：やさしい日本語

使うには、次の準備が必要です。

  1. 試験版の ELMO_key を、すべてのリリースの中の「Pre-release」と書かれた版からダウンロードしてインストールします（上のダウンロードボタンは、試験版ではない版です）。
  2. AI のモデル（約 2GB）をダウンロードします：sarashina2.2-3b-instruct-v0.1-Q4_K_M.gguf（SB Intuitions 社のモデル、MIT ライセンス）。
  3. エクスプローラーのアドレス欄に C:\ProgramData と入れて開き、ELMO_key フォルダーとその中に models フォルダーを作って、ダウンロードしたファイルを入れます（C:\ProgramData\ELMO_key\models）。
  4. 設定画面の 入力補助 タブ →「AI で書き直す（試験版）」にチェックを入れて OK を押します。

書き直しは PC の中だけで行い、文章を外に送りません。最初の 1 回は AI の準備に数十秒かかります。メモリ 8GB 以上の PC を推奨します。小さな AI なので、意味が変わったり不自然になったりすることがあります。出た文は必ず確認してから使ってください。

機能をオフにしている間、Ctrl + E はこれまでどおり（カーソル移動など）に働きます。Ctrl + T は、いつでもこれまでどおり（半角英数に変換）です。

Mozkey や Mozc と一緒に使えますか？

使えません。エルモキーは Mozkey（Mozc をもとにした日本語入力ソフト）をもとに作っていて、内部のしくみが共通しているためです。どちらかが入っている場合は、先にアンインストールしてください。

ダウンロードしたファイルが本物か確かめたい（詳しい方向け）

PowerShell で次のコマンドを実行し、表示された値が GitHub のリリースページに書かれた SHA-256 の値と同じか確かめてください。

Get-FileHash "$env:USERPROFILE\Downloads\ELMO_key_x64.msi" -Algorithm SHA256
